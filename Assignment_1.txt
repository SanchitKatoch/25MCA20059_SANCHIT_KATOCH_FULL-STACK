You are required to build a fully responsive front-end mini project collection using only HTML, CSS, and JavaScript 
fundamentals.
The assignment consists of three parts: 

-- first, implement an Infinite Scroll Skeleton Loader using pure CSS and structured semantic HTML fragments to 
simulate loading content placeholders with smooth shimmer effects;

-- second, design and develop a modern Analytics Dashboard featuring responsive KPI cards, adaptive grid systems, 
charts/placeholders, and professional table layouts that adjust seamlessly across desktop, tablet, and mobile screens;
 
-- third, create an Amazon Homepage Clone with responsive navigation bars, product sections, banners, 
reusable utility classes, and flexible layouts following modern UI design practices. 

-- Students should focus on clean code structure, reusable components, responsive web design principles, 
CSS positioning techniques, Flexbox/Grid usage, accessibility, and consistent styling conventions. 

-- The final submission should demonstrate proper folder organization, mobile responsiveness, optimized styling practices, 
and pixel-perfect UI implementation inspired by real-world production interfaces.
